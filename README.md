# 🎮 Julfed Studio 2.0

**Игровая студия в кармане.** Telegram-бот, который прямо с телефона (Termux) превращает ИИ-модели в команду разработчиков: ты задаёшь направление игры, а «планировщик» придумывает идеи, раскидывает задачи по моделям разной мощности, пишет код в твой Godot-проект, коммитит в GitHub и присылает готовый APK.

> Никакого ПК. Только телефон, Termux и Telegram.

---

## ✨ Возможности

- 🧭 **Направление игры** — одна цель (`/direction`), от которой отталкивается вся студия
- 🤖 **Автопилот** (`/autopilot`) — планировщик сам придумывает идеи, разбивает их на задачи и отдаёт исполнителям
- 👥 **Команда моделей** (`/team`) — четыре роли с отдельной моделью и уровнем усилия:
  | Роль | Для чего |
  |------|----------|
  | `planner` | придумывает идеи и разбивает на задачи |
  | `heavy` | самое сложное: тайлмапы, карты, архитектура, ИИ врагов |
  | `mid` | обычные механики, сцены, интерфейс |
  | `light` | спрайты и анимации, простые скрипты, звуки, тексты |
- 📋 **Очередь задач** — ручные задачи (`/task`), цикл выполнения (`/loop`), просмотр и очистка очереди
- 📦 **Сборка APK** (`/build_apk`) — запускает GitHub Actions, ждёт релиз и присылает APK в чат
- 🔀 **Авто-коммиты** — изменения проекта пушатся в GitHub
- 📎 **Вложения в любой команде** — текст/`.gd` как промпт, фото и видео как контекст для модели, `.zip` как замена проекта
- 📁 **Работа с файлами** — скачать файл, весь проект архивом, загрузить файл или проект
- 💳 **Учёт лимитов** — расход токенов, окно 5 часов, кредиты

## 🧱 Как это устроено

```
Telegram  ──►  bot.py  ──►  Codex CLI  ──►  Godot-проект
                │                              │
                └──► build.py ──► git push ────┘
                          │
                          └──► GitHub Actions ──► APK ──► обратно в Telegram
```

| Файл | Назначение |
|------|------------|
| `bot.py` | Telegram-бот, все команды, автопилот и планировщик |
| `build.py` | запуск Codex, очередь, git, GitHub API, работа с файлами, учёт токенов |
| `config.py` | чтение `.env` и `studio_config.json` |
| `setup_termux.sh` | установка всех зависимостей в Termux |
| `start.sh` | запуск бота с блокировкой сна телефона |

## 🚀 Установка

### Что понадобится

- Android-телефон с [Termux](https://f-droid.org/packages/com.termux/) (лучше из F-Droid)
- Токен бота от [@BotFather](https://t.me/BotFather) и твой Telegram chat ID
- Аккаунт для авторизации в Codex CLI
- Godot-проект в GitHub-репозитории с workflow `release.yml`, который собирает APK и публикует релиз (нужен для `/build_apk`)

### Шаги

```bash
# 1. Клонируй репозиторий
git clone https://github.com/<твой-ник>/Julfed-Studio-2_0.git ~/studio
cd ~/studio

# 2. Установи зависимости (Python, Node.js, git, Codex CLI и т.д.)
bash setup_termux.sh

# 3. Авторизуйся в Codex
codex login

# 4. Создай файл .env (см. ниже)
nano .env

# 5. Запусти студию
bash start.sh
```

### Настройка `.env`

```env
# Обязательные
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789

# Путь к Godot-проекту (по умолчанию ~/project)
PROJECT_PATH=/data/data/com.termux/files/home/project

# Для сборки APK и пуша в GitHub
GITHUB_REPO=ник/репозиторий-игры
GITHUB_TOKEN=ghp_...

# Необязательные
CODEX_PATH=codex
ANDROID_PRESET=Android
```

## 🕹 Команды

### Главное
| Команда | Описание |
|---------|----------|
| `/direction <цель>` | задать направление игры |
| `/autopilot [N]` | запустить студию (N — максимум идей) |
| `/build_apk` | собрать APK через GitHub Actions |
| `/stop` | остановить работу |

### Ручные задачи
| Команда | Описание |
|---------|----------|
| `/task <промпт>` | добавить задачу в очередь |
| `/loop` | выполнять очередь по кругу |
| `/queue` | показать очередь |
| `/clear` | очистить очередь |
| `/luna <промпт>` | разовый запрос напрямую в Codex |

### Файлы
| Команда | Описание |
|---------|----------|
| `/get <файл>` | получить файл из проекта |
| `/download_project` | скачать весь проект архивом |
| `/upload_project` | заменить проект на присланный `.zip` |
| `/upload_to <путь>` | загрузить файл в указанное место проекта |

### Настройки и статистика
| Команда | Описание |
|---------|----------|
| `/model` | выбрать модель |
| `/effort` | выбрать уровень усилия |
| `/team` | настроить роли команды |
| `/credits`, `/credits_limit`, `/credits_reset` | кредиты |
| `/limit5h` | лимит за 5-часовое окно |
| `/status` | текущее состояние |
| `/cancel` | сбросить все вложения |

### 📎 Вложения
Прикрепляй файлы к любой команде:
- `.txt`, `.md`, `.gd` и др. → используются как промпт
- фото / видео → отправляются в Codex как контекст
- `.zip` → замена проекта

## ⚙️ Пример рабочего процесса

1. `/direction Хоррор-рогалик в пиксельной стилистике с процедурными подземельями`
2. `/team heavy gpt-6-astra high` — настрой, какая модель делает самое сложное
3. `/autopilot 5` — студия сделает до 5 идей
4. Следи за отчётами в чате, при необходимости останови через `/stop`
5. `/build_apk` — получи готовую сборку прямо в Telegram

---

## ⚠️ Важно

- Telegram-токен и GitHub-токен храни **только** в `.env` и никогда не коммить его в репозиторий. Добавь `.env` в `.gitignore`.
- Бот может менять файлы проекта и делать коммиты автоматически. Держи резервную копию игры.
- Сборка APK работает только через GitHub Actions: локально на Termux она не поддерживается.
- Автопилот расходует лимиты Codex. Следи за `/credits` и `/limit5h`.
